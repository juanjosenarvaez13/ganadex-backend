# 🐄 Ganadex

> Sistema Integral para la Gestión de Fincas Ganaderas desarrollado con Spring Boot y React.

## 📖 Descripción

Ganadex es una aplicación web diseñada para facilitar la administración y el control de una finca ganadera.

El objetivo del sistema es centralizar toda la información relacionada con los animales, potreros, inventario de insumos y demás procesos que se realizan diariamente en una explotación ganadera.

Este proyecto nace de una necesidad real y está siendo desarrollado como un proyecto de portafolio aplicando buenas prácticas de arquitectura de software, desarrollo backend y diseño de aplicaciones escalables.

# 🏗️ Arquitectura

El proyecto sigue una arquitectura modular (Feature-Based Architecture), donde cada módulo contiene todos sus componentes relacionados.

Ejemplo:

```
animal
├── controller
├── dto
│   ├── request
│   └── response
├── entity
├── mapper
├── repository
└── service
```

Esta organización facilita la escalabilidad, el mantenimiento y la comprensión del proyecto.
